## 6. V1.4 保留边界

- Agent 事件回放适用于单实例；多实例实时广播尚未接消息组件。
- 客户端断开不会取消调查，但还没有显式取消 API、幂等键和全链路超时预算。
- 对话 SSE 仍是完整回答落库后的协议分块，不是模型 Provider 原生 token 流。
- 高风险提案已经具备治理审批，但没有生产执行器，这是当前版本有意保留的安全边界。
- MySQL 部署路径已提供，CI 尚未使用 Testcontainers 做真实 MySQL 回归。
