# V1.7 checkpoint-09：事务 Outbox 与租约领取

日期：2026-09-08。状态：事务 outbox 与领取基础已验证，Redis 投递尚未接入。

## 实现

V16 新增 agent_event_outbox，以 event_id 主键引用原始事件，不复制正文。`opspilot.agent.events.outbox-enabled=true` 时，事件和待投递行在同一事务写入；默认 false，保持本地演示无需 Redis。历史事件不回填，新开启后仅新事件进入 outbox。

AgentEventOutbox 按到期 PENDING 或租约过期 CLAIMED 行扫描，通过带条件 UPDATE 原子领取，随机租约 token 保护确认/退回；过期租约不能确认。attempts 在每次领取时递增，retry 指定下次尝试时间，DELIVERED 不再领取。批次限制 1–100，无全局高水位，因此较小 ID 晚提交仍是可扫描候选。方法由分发器在无外层事务的调度入口调用，网络请求安排在领取结束之后。

## 验证

H2 事务测试扩展验证事件与 outbox 一起提交/回滚；租约测试使用显式时间推进验证到期重领、旧 token 无权确认/退回、重试延迟和重复确认。MySQL 条件套件新增双 relay 闸门竞争、唯一领取与到期 token 保护，并将空库迁移断言推进到 V16；全链路事件须每条对应一个 PENDING outbox。

本地 5 项事务/租约测试通过。首轮 [CI 34240750409](https://github.com/Trigger726/OnCall-Agent/actions/runs/34240750409) 前端/H2 通过，MySQL 在精确租约到期重领时失败；V16 默认秒级 TIMESTAMP 与 Java 亚秒时间不一致。新增 V17 将 outbox 时间列升级为微秒，领取/确认/重试入口时间统一截断至微秒，保留已发布 V16 校验和。第二轮远端结果待验。领取逻辑不含 Redis 调用，测试不冒充真实 Redis 验证。
