## 本轮生产能力

新增 V41 outbox，发布请求、原候选快照、审计与通知行在同一事务提交。每个原候选只生成一个事件版本0、稳定随机投递键与冻结载荷；原请求键重放只读取原回执，不重建或补发事件。空原候选不因后续授权补入新人，默认关闭不回填旧发布。最多500候选及60000 UTF-8字节，超限413且整笔回滚。

新增管理员配置的 webhook 网关适配器，默认 disabled，不访问外部渠道。启用时校验 HTTPS（仅本机 HTTP 例外）、令牌、重试和超时/租约预算，不跟随重定向。单 worker、无内存排队；SQL 有限批扫描，逐行 CAS 租约，网络调用不持有事务。发送前重新核验原候选当前资格，撤权、停用、计划失效、来源取消、已认领/撤回均跳过。2xx 仅记技术成功；429/5xx/传输失败有限退避，其他非成功永久失败。旧租约迟到回执不能覆盖新 worker，剩余租约不足完整发送预算时不启动 HTTP。

发现并修复配置调低最大尝试次数后的旧 PENDING 队头阻塞：达到新上限的到期事件转 FAILED/ATTEMPTS_EXHAUSTED，无额外 HTTP。attempts 统计租约获取，不等于接收端收到请求数。稳定键供渠道去重，不承诺 exactly-once。

新增认证 GET `/api/v1/on-call/open-handoffs/{id}/notifications` 只暴露技术元数据，不暴露冻结正文、渠道令牌、URL 或租约持有人。publication 的 `deliveryImplemented=true` 仅指适配器存在；当前 `enabled` 独立展示，不能推导实际发送或人已接班。既有全局读权限未变，不宣称新增私有计划读隔离。
