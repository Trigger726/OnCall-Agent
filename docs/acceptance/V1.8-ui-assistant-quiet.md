## 正常完成的安全条件

自动恢复输入前，必须从服务端取回原请求状态与会话，核对：

1. 当前视图、账号租约和原 intent 仍有效；迟到的旧回读不得覆盖新的请求。
2. 服务端状态是 COMPLETED，回读会话 ID 等于原会话。
3. USER 消息 ID 与回执 questionMessageId 一致，内容等于原冻结问题。
4. ASSISTANT 消息 ID 与 answerMessageId 一致，是非空且非 provisional 的保存结果。
5. 本地原 intent 清除成功后才释放输入；清除失败保留锁定、提示及重试操作。

满足后仅中止并释放这个**已完成请求的本地旧读取器**，不发送服务端取消命令，再清空当前成功提示。sending/requestControl 围栏直到原操作 finally 才解除。已确认取消/超时等仍在当前页面显示终态并等待显式继续；未确认请求保留原键，不自动重发。无法清除本地记录时，重试按钮也捕获存储异常，不产生未处理异常或新 POST。
