日期：2026-09-10。状态：接收器检查点通过，完整分布式订阅尚未完成。

## 实现与范围

启用 outbox 后，每实例使用独立单线程调度器，每秒非阻塞 XREAD 至多 100 条通知；不使用共享消费组。游标从 `0-0` 开始，逐条推进 Redis ID，重启重读仍保留的通知。只接受 schemaVersion=1 与正数 runId/eventId，并发布本地标识事件，不接受正文。无效通知跳过，Redis/同步监听器异常保留失败位置待下轮重试；之前已完成的监听器可能重复收到，不能宣称 exactly-once。

参考 [Spring Data Redis Streams](https://docs.spring.io/spring-data/redis/reference/redis/redis-streams.html) 的显式读取游标，避免每轮使用 latest 导致轮询间隙漏读。独立调度器避免接收失败占用 outbox 发送线程。监听器必须仅入队/合并通知，不能在回调内直接发送 SSE。
