## 2. 用户真正可操作的流程

`/on-call` → 班次维护的“发布开放接班” → 选择本人普通班次内整秒子时段、填写说明 → 核对最新源班次与当前人员/计划 → 可靠保存原意图 → 本人发布。另一当前合格用户在“可认领候选”或“全部历史”打开请求，点击“我自愿认领”，不能指定代认领人。本人可撤回未关闭请求，已结束/停用计划不妨碍本人关闭历史需求。

原意图以本账号、本标签页sessionStorage隔离，包含动作、源/请求快照、显式原版本、规范UUID和原说明；首次发送前写入后再读取确认完全相等。配额、读失败、静默不保存或损坏都不能继续创建不留原意图的POST。收到结果不明确时冻结原内容，不自动重试、不换键、不更新版本；刷新只GET。403/409原意图锁定，存储锁定失败则本地进一步禁止操作并明确警告，不能保证存储持久性。

新认领前重新GET请求和相同计划/时段台账，源取消/版本改变、人员/计划不活跃、截断、到期或已观察覆盖冲突不能使用旧事实POST。此客户端快照不是最终授权；真实服务器锁后检查仍是权威。原已提交意图的手动求回执不是创建新责任，不用当前取消/结束状态错误禁止原回执。

详情、账号、凭证及卸载都用epoch、页面账号、已存账号和token隔离旧响应。旧200已经在服务器提交，也不能覆盖另一个详情、清除新账号或同账号新凭证下另一个原意图；旧意图保留给真正本人手动回执。跨标签页storage变化另有失败关闭处理，但本轮未把此路径冒称已实页验收。
