## 1. 同一套真实 HTTP 场景，不另造简化版本

AssistantNativeEndpointIntegrationTest 保留现有真实随机端口 servlet、实际登录 JWT、受控独立模型 HTTP、唯一模型 worker/队列容量 1、原预算 8 秒以及全部原断言。默认仍为 H2；仅显式配置 opspilot.assistant.native.mysql.enabled=true 才注册 Spring 管理的 MySQL 8.4 Testcontainer，数据库使用 utf8mb4。每次实际执行从 JDBC metadata 核验选中的产品/版本，并输出不含地址、凭据、Token 的 CP80_NATIVE_DATABASE 标记。

条件化 @Bean/@ServiceConnection 采用 Spring 生命周期，不在 @AfterAll 提前停库。连接覆盖与容器生命周期依据 [Spring Boot 3.2.0 官方说明](https://docs.spring.io/spring-boot/docs/3.2.0/reference/htmlsingle/#features.testing.testcontainers.service-connections)，另核对本仓库实际 3.2.0 字节码。最终审计失败注入沿用独立 CHECK 约束，MySQL 8.4 的 [ALTER TABLE 官方语法](https://dev.mysql.com/doc/refman/8.4/en/alter-table.html)支持 DROP CONSTRAINT；尚需真实 CI 执行验证，不以文档代替运行。

九种方法共 18 次执行：实际 token 先于持久化完成、预览后显式取消并复用 worker、预览后原预算超时、队列满接纳前拒绝、截断 EOF 十次、浏览器断开后原请求继续、认证撤销、清空后的晚结果不复活、最终审计失败事务回滚。新增队列场景以实际 HTTP 和 SQL 检查 QUEUED，503/ASSISTANT_QUEUE_SATURATED、拒绝键 GET 404、问题/答案/模型调用零新增；取消排队后以相同原键重新排队，取消运行中请求后，在旧 Provider 未放行时完成新原生答案。没有 Mock MVC、伪造响应或扩大预算。
