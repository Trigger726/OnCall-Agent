# V1.8 CP08：引用原文的版本与权限闭环

2026-10-15，接续助手精简版 `db45137`。本轮最终限定验收通过：163 Java、266 前端、292 脚本测试及新旧真实整包对比。下面的中途记录和失败按发生时点保留，不是长期目标已完成或真实云模型质量证明。

## 已核对的真实缺口

原始 OnCall 有文档搜索/问答，当前 OpsPilot 已有按问题检索与稳定的 `runbook:{key}:v{version}#chunk-{index}` 引用，但助手证据列表只能展示文本编号。原 `GET /runbooks/{key}/versions` 返回可见版本列表，没有精确的版本/片段读取入口；不能据此声称用户能从回答一键核对原文。

参考 [LlamaIndex 官方引用工作流](https://developers.llamaindex.ai/python/examples/workflow/citation_query_engine/)将来源节点与引用对应的思路。本轮自己的工程选择是读取数据库中的被引用片段，不采用模型生成的链接，不安装该库或调用其示例中的云模型。不是与其质量等价或优于原 Milvus 的结论。

## 实现范围与待验条件

- 新增只读 `GET /api/v1/runbooks/{stableKey}/versions/{versionNo}/chunks/{chunkIndex}`；精确三元组查询，同一 SQL 中限制 PUBLISHED/SUPERSEDED 与当前角色 ACL。缺失、未发布及无权访问统一 404，不以助手历史证据为访问授权，不把旧引用替换为最新版本。
- 返回真实存储片段、章节、标题、来源、发布时间、版本与状态；不采用搜索时截短的 600 字 excerpt，不暴露其他片段/版本。
- 助手展开证据后，对规范 Runbook 引用提供“查看原文”；其他证据类型仍按原样展示，不构造任意外链。原回答、复制、导出及数据库内容不变。
- 原生 dialog 支持键盘关闭和焦点约束；历史版本明确标识为非当前指引。原文用 Vue 文本插值保留换行，不执行 HTML；网络/无权限状态不显示旧内容。
- 读请求绑定原登录 token，响应/JSON 回读后再次检查；关闭、切换会话或账号时撤销旧读取，不让迟到原文回填新上下文。

按 `karpathy-guidelines` 限定为引用闭环；`frontend-design` 沿用既有双主题颜色（浅色 #ffffff/#171717/#636363/#dedede/#386b0a，深色继承现有 token）、MiSans 与 14px/1.85 原文排版，采用居中原文阅读层，不重做导航/流光。`frontend-testing-debugging` 的验证目标是：助手真实回答 → 展开证据 → 读取精确版本片段 → 关闭返回原对话。Browser plugin/`browser` skill 不可用，使用已安装 Playwright/Chrome，不新增依赖。

验收覆盖 H2 集成、原 Runbook/助手选择回归、前端请求与生命周期、生产构建、新旧整包、双主题桌面/手机、错误/账号切换/关闭后迟到响应、来源版本不变及历史包保护。以下单列证据与未测边界，不把 mock UI 或源码存在冒充验证。
