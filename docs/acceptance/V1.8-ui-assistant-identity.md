# OnCall 助手身份回答修复与 Claude design 页面细修

2026-10-14，接续 [默认流光](V1.8-ui-ambient-autoplay.md)。用户要求使用 Claude UI design 优化助手页面，并检查“你是谁 / 你是什么模型”的答非所问。仅本轮范围，不代表 CP07 或长期目标完成。

## 复现与原因

在用户当前 `http://127.0.0.1:9900/assistant?session=4` 页面查看后，新建独立测试会话，不清空、删除或修改原对话。依次输入两个问题，原版均返回通用自我介绍、活跃 Incident 和 Runbook 检索依据。当前启动脚本明确设置 `opspilot.ai.enabled=false`；规则兜底没有身份意图分支，不能将该行为描述成真实云模型理解失败。

旧页面加载的动态按钮在刷新后消失，是旧前端仍留在已打开页面；不重新加入控制，不改默认动态背景的决定。

## Skills 与设计约束

使用已安装的 Anthropic 官方 `frontend-design`，即先前用户要求的 Claude UI design skill（[历史来源与固定版本](V1.7-ui-claude-design.md)）。这是设计工作说明，不是调用 Claude 模型。按 `frontend-app-builder` 的既有设计系统小改例外，不生成全新栅格概念；使用 `karpathy-guidelines` 控制范围，`frontend-testing-debugging` 验证实际页面。Browser plugin / `browser` skill 不可用，使用既有 Playwright / Chrome；另通过 IAB 实际复现原始问题。

锁定已有双主题：深色 `#090909/#111111/#f5f5f5/#a3a3a3/#2b2b2b`，浅色 `#f7f7f7/#ffffff/#171717/#636363/#dedede`，薄荷流光与本地 MiSans 不变。保持原三栏语义与导航，正文 14px/1.85，标题 23–30px/600；消息最大宽 780px，输入区 724px，缩减会话栏 232px、上下文栏 280px。900px 以下会话栏转抽屉，使用动态视口高度，减少小屏遮挡。不要另建营销首页、暖色主题、陌生字体或装饰性数字。

视觉重点是问题、回答与输入区：助手回复去掉重复细边框，保留高不透明度阅读底色；用户消息保持气泡。多行输入明确提示 Enter / Shift+Enter，并防止中文输入法选字 Enter 提前发送。允许的文案变化仅为真实运行模式、上下文栏标签、欢迎说明和输入提示；既有导航、事件数据、操作按钮及真实业务不变。

## 实现边界

- `AssistantIdentity` 仅识别完整身份/能力/问候问题与组合，混合故障问题仍走原证据路径；不以包含“模型”或“谁”为依据粗暴分流。
- 两类已知身份问题在普通 HTTP 与 SSE 中共用同一持久化流程；跳过 Runbook、模型历史及外部取证，不拼接当前故障/手册引用。
- 规则模式诚实说明“未启用大语言模型”；启用时读实际 `ChatModel` 默认选项，仅允许安全模型标识。无法确认型号时不猜；配置存在不等于云服务可用，本次身份说明没有调用模型。
- 新增需登录的 `/api/v1/assistant/runtime`，前端运行模式来自后端；无法获取时显示“运行模式待确认”，不硬编码 Claude / DeepSeek 或伪造已连接。
- 原账户权限、取消/超时 checkpoint、幂等内容绑定、最终事务及撤权围栏仍在。无关生产业务、迁移、待验 CP07、V1.7 封版、旧演示 JAR 和用户历史不覆盖。
