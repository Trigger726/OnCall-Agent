# V1.7 checkpoint-41：Actuator 管理监听隔离

日期：2026-09-25。状态：通过（限本检查点）；H2 全量、前端、打包 JAR 双端口，以及远端 MySQL/十一项 CI 已闭环。

## 问题与改动

此前 `/actuator/prometheus` 和业务 API 共用 `9900` 监听，任何能访问业务入口的网络客户端都可读取 JVM、HTTP 与连接池指标。当前改为 JAR 默认在 `127.0.0.1:9920` 提供管理端点，业务端口不映射 Actuator；Compose 为同网络 Prometheus 访问，在容器内监听 `0.0.0.0:9920`，但宿主机只映射 `127.0.0.1:9920`。Prometheus 改抓取 `opspilot:9920`，宿主机 Prometheus UI `9090` 也限回环访问；脚本、双 JVM 测试和容器启动门禁同步更新。开发代理不再转发 `/actuator`。

Spring Security 原有字符串路径匹配器在独立管理 Servlet 中触发 500，改用显式路径匹配器处理两个管理端点。不存在的静态资源原被通用异常处理映射成 500，现返回 404。独立端口测试使用真实 HTTP，断言业务端口指标路径 404、管理端口指标 200 且包含 JVM 指标、管理健康为 `UP`。普通 Spring 测试上下文关闭第二监听，避免多个缓存上下文抢占固定 `9920`；独立端口测试显式启用随机管理端口。
