## 怎么运行

已有本机 Demo JAR 时，在仓库根目录运行：

```powershell
java -jar target/opspilot-v1.7-ui-claude.jar
```

默认入口 `http://localhost:9900`，管理端口 `127.0.0.1:9920`；先确认空闲。JAR 默认使用当前目录的 `data/opspilot-demo` H2 文件，启动会执行迁移/演示初始化：不想触碰已有演示数据时不要使用此命令，改用下面的隔离复验。不要把多个版本连接到同一已有数据库。初始演示账号 `admin` / `OpsPilot@2026`，AI 与外部通知默认关闭；演示密码不能用于生产。

新环境可将推荐 UI 分支 clone 到**新的空目录**，从该根目录执行 `.\mvnw.cmd spring-boot:run`。已有 dirty 工作区不需要切换、reset 或恢复文件。源码编译目标 Java 17；当前本机 JAR 和浏览器验收使用 JDK 21，未重做 JDK 17 实机验证。静态资源已提交，单纯查看不必安装 Node/npm 或构建前端；Maven Wrapper 首次运行仍需要下载依赖。

需要完全隔离的自动验收：

```powershell
node scripts/verify-ui-packaged.cjs --jar target/opspilot-v1.7-ui-claude.jar
```

使用既有 JAR、新临时 H2 和独占 loopback 端口，完成后认证关闭进程；前提和环境变量见[详细运行说明](../acceptance/V1.7-ui-repeatable-qa.md#运行入口)。不会复制/覆盖 JAR、连接用户数据库或自动安装依赖。
